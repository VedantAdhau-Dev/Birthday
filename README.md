# Premium Story Website

## Replace these assets

Put your files inside `assets/` with these exact names:

- `video-1.mp4` — first full-screen video
- `video-2.mp4` — second full-screen video
- `image-01.jpg` through `image-07.jpg` — seven 16:9 photos
- `chat-01.jpg` through `chat-04.jpg` — chat screenshots

You can use PNG/WebP too, but update the extensions in `index.html`.

## Run

Open `index.html` directly in a browser, or use any simple local server.

Example:
`python -m http.server 8000`

Then visit:
`http://localhost:8000`

## Customize

Edit the `storyLines` array in `script.js` for the opening story.

Edit the birthday text in `index.html`.

The first video and second video deliberately expose only play/pause controls.
